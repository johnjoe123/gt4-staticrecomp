# 2026-11-19

## LAN battle over the internet (contributor branch `task/online-lan-tunnel`)

Written on a Linux host without the game or the Windows toolchain; nothing was run in the game.

- `native/net_smap.*`: Network Adaptor model (DEV9 expansion-bay registers, SPEED, SMAP FIFOs and descriptor rings,
  EMAC3, PHY, MAC EEPROM, PIO and DMA channel 8, IOP interrupt line 13). `native/net_link.*`: non-blocking UDP link to
  the bridge on 127.0.0.1. `native/net_runtime.*`: the machine's one instance, on only with `GT4_NET=1`.
- `scripts/prepare_net_runtime.py`: net capsule over the donor or the USB capsule `hw.cpp`; CMake
  `GT4_NET_RUNTIME_SOURCE`. Derived files pass `g++ -fsyntax-only` against the pinned donor headers (both inputs).
- `net/`: `gt4net` (Rust): lobby server (HTTP + WebSocket, six seats, DHCP and router ARP in the switch), bridge,
  command line with `host --cloudflare`.
- Checks run: `net_smap_fixture` with g++ 20 `-fsanitize=address,undefined` (ok); `cargo test` in `net/` (7 unit, 3
  end-to-end, ok); `python -m unittest tests/python/test_net_runtime.py tests/python/test_usb_runtime.py` (11, ok).
- Not run: clang-cl build, CTest on Windows, any game boot. Limits and the owner test plan are in `docs/ONLINE-LAN.md`.
